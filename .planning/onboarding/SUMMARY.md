# Onboarding Summary — LNCT Connect Frontend MVP

## Key Discoveries & Findings
- **Stack**: React 18, Vite, TypeScript, Tailwind CSS v4, Three.js / R3F / Drei, Framer Motion, GSAP, Lucide React.
- **Application Nature**: Frontend-only MVP for an LNCT student and alumni networking platform.
- **Routing Structure**: 11 distinct routes managed by `React Router DOM` in `src/App.tsx`.
- **Components & Layout**: Rich glassmorphism aesthetics, custom 3D particle background scene (`NetworkScene.tsx`), and responsive layout wrapper (`AppLayout`).
