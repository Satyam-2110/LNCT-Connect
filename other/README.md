# Supporting Materials (`other/`)

This directory contains supporting project documentation, audit reports, architecture specifications, and non-application reference assets.

## Directory Structure

- **`documentation/`**: Extended project documentation, setup guides, and operational notes.
- **`reports/`**: Code review audits, milestone reports, and verification logs.
- **`architecture/`**: System architecture contracts, database ERDs, and design documents.
- **`assets/`**: Brand guidelines, external logos, presentation assets, and non-application media.

---

*Note: Application source code resides in `frontend/`, backend database migrations and management utilities reside in `backend/`, and GSD task plans reside in `.planning/`.*
